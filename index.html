📖 How to Use This Site

This site turns the entire OpenStax Microbiology textbook into a fast, fun, and organized study experience. Here’s the best way to use it:

  1. Start here — Read the How to Use page for a full study strategy.
  2. Study by chapter — Use the sidebar to navigate chapters 1–26 in order, or jump to what you need.
  3. Use the Glossary — Search any term instantly on the Glossary page or use the search bar above.
  4. Practice — After each chapter, go to Practice for MCQs, short-answer, and flashcards.
  5. Exam Week — Use Exam Week Mode for ultra-condensed summaries right before your test.
  6. Cheat Sheets — See Cheat Sheets for key pathways, cycles, and comparison tables.
